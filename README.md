# Rogue Fits

Rogue Fits is a responsive fashion and streetwear retail website built with React JS. The platform showcases carefully selected sneakers, clothing and accessories for individuals who value quality, comfort and personal style.

## Features

- Responsive homepage with a promotional hero section.
- About page with the business background, mission, vision and objectives.
- Shop page displaying products, prices and descriptions.
- Reusable ProductCard component for displaying products.
- Contact page with a form for customer enquiries.
- Form validation and submission feedback.
- Navigation between pages using React Router.

## Technologies Used

- React JS
- JavaScript
- Vite
- HTML
- CSS
- React Router DOM

## Installation and Setup

1. Clone the repository.
2. Open the project folder in your terminal.
3. Install the dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in your terminal.
